Loxone-Anbindung

Server: {{ host }}

Der guntacontrol-Server bietet eine Klartext-HTTP-Schnittstelle für den Loxone Miniserver: Werte lesen per Virtuellem HTTP/UDP Eingang, schalten per Virtuellem Ausgang. Schalten erfordert allowWrite: true in der Konfiguration und ausgeschalteten Schreibschutz (⚙ → Sicherheit).

1 · Werte lesen (Virtueller HTTP Eingang)

Abfrageadresse auf /loxone/status, dann je Wert einen Befehl mit Befehlserkennung Schlüssel=.

http://{{ host }}/loxone/status

Einzelwert ohne Werterkennung:

http://{{ host }}/loxone/get?name=Kesseltemperatur

2 · Werte lesen per UDP-Push (empfohlen)

In der Konfiguration loxone.udp: <Miniserver-IP>:7000 setzen. Dann in Loxone einen Virtuellen UDP Eingang auf Port 7000 anlegen und Befehle mit Befehlserkennung Schlüssel= ergänzen – wie beim HTTP-Eingang. Datagramme sind < 1200 Byte, ohne Zeilen zu zerreißen.

3 · Steuern (Virtueller Ausgang)

Adresse http://{{ host }}, Befehl bei EIN /loxone/set?syn=<SYN>&value=<v> (GET). Antwort OK oder ERR: ….

Betriebsmodus – syn=PR001

Weitere: BK006/BK106/BK206 = WW-Nachladung (value=1). Die Heizzeiten selbst sind nicht per API änderbar (Gerätegrenze).

4 · Audit-Log

Jede Änderung (Loxone/Web/API) wird protokolliert – Zeit, Client-IP, Quelle, Parameter, Wert, Ergebnis:

http://{{ host }}/api/audit?limit=100

Server mit -audit guntamatic-audit.log starten für die dauerhafte Datei (JSON-Zeilen).
